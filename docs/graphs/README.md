# Repository charts

Glyph provides live SVG repository charts for public GitHub repositories.
The chart is generated by the Vercel API and refreshes from GitHub periodically.

## Chart types

Use the `/chart` route with `owner`, `repo`, and an optional `type`:

| Type | Description |
|---|---|
| `stars` | Weekly cumulative star history. This is the default. |
| `commits` | Weekly commit activity for the last six months. |
| `contributors` | Contributions from the top eight contributors. |
| `languages` | The repository's top eight languages by bytes. |
| `releases` | The twelve most recent published releases. |

All chart types use the same dark Glyph card, purple visual style, GitHub
repository header, and responsive SVG dimensions.

## Parameters

| Parameter | Description | Example |
|---|---|---|
| `owner` | GitHub repository owner or organization. | `owner=benjamin-blanke` |
| `repo` | GitHub repository name. | `repo=glyph` |
| `type` | Chart type: `stars`, `commits`, `contributors`, `languages`, or `releases`. | `type=commits` |

Direct URL:

```text
https://glyphbadges.dev/chart?owner=OWNER&repo=REPOSITORY
```

GitHub API failures are returned explicitly so an unavailable chart is not
mistaken for valid data. Charts currently support public repositories with
accessible GitHub API data; private repositories require an authenticated
server-side integration, which is not enabled by default.
