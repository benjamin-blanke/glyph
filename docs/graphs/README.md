# Glyph graphs

Graph assets are hosted on GitHub Pages. They use a dark card, GitHub logo, purple line, gradient fill, and Glyph branding. Zero-value metrics render as a clean baseline instead of a misleading one-point chart. A scheduled GitHub Action refreshes them daily.

```md
![Stars](https://benjamin-blanke.github.io/glyph/graphs/stars.svg)
![Forks](https://benjamin-blanke.github.io/glyph/graphs/forks.svg)
![Open issues](https://benjamin-blanke.github.io/glyph/graphs/issues.svg)
![Watchers](https://benjamin-blanke.github.io/glyph/graphs/watchers.svg)
```

Run `npm run update:graphs` locally to refresh the graph for `GLYPH_REPOSITORY=owner/repository`.
