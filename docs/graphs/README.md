# Repository charts

Glyph provides a live SVG star-history chart for public GitHub repositories.
The chart is generated by the Vercel API and refreshes from GitHub periodically.

## Star history

Use the `/chart` route with the repository owner and name:

The `repo` value should contain only the repository name:

```md
![Star history](https://glyphbadges.dev/chart?owner=benjamin-blanke&repo=glyph)
```

## Parameters

| Parameter | Description | Example |
|---|---|---|
| `owner` | GitHub repository owner or organization. | `owner=benjamin-blanke` |
| `repo` | GitHub repository name. | `repo=glyph` |

Direct URL:

```text
https://glyphbadges.dev/chart?owner=OWNER&repo=REPOSITORY
```

The chart includes the repository name, current star count, historical trend,
date range, and Glyph branding. GitHub API failures are returned explicitly so
an unavailable chart is not mistaken for valid data.

The chart currently supports public repositories with accessible GitHub star
history. Private repositories require an authenticated server-side integration,
which is not enabled by default.
