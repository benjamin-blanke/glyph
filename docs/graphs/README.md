# Glyph graphs

Graph assets are hosted on GitHub Pages. The star graph uses the same dark card, GitHub logo, purple line, gradient fill, and Glyph branding as the reference design. A scheduled GitHub Action refreshes it daily.

```md
![Star history](https://benjamin-blanke.github.io/glyph/graphs/stars.svg)
```

Run `npm run update:graphs` locally to refresh the graph for `GLYPH_REPOSITORY=owner/repository`.
