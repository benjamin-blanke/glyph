# Status badges

## Dynamic Livck badge

```md
![Livck Beta](https://glyphbadges.dev/badge/livck?url=https%3A%2F%2Fstatus.waveserv.com)
![Status](https://glyphbadges.dev/badge/Status-Degraded-F59E0B.svg?text=Degraded&color=F59E0B&labelColor=23272A&logo=status)
```

The Livck badge is **Beta** and reads the public status page on every request.
Use URL encoding for the status-page URL.

Supported Livck states are Operational, Degraded, Down, Maintenance, Incident,
Investigating, Monitoring, and Resolved.
